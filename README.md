## Daily routine (about 8–10 hours a day)

1. **Read the day's file** (3–4 hrs). Don't memorize. Make sure you can *explain it out loud*.
2. **Practice** (2–3 hrs). On Day 2 write the SQL by hand on paper. On Day 4 say your stories out loud.
3. **Self-test** (1 hr). Every file ends with a "Can you answer these?" list. Cover the answers and speak.
4. **Sleep properly.** A tired brain blanks on easy questions.

## Golden rules for the interview

- **Answer in 3 layers:** a one-line definition, then a simple example, then when or why you'd use it.
- **Tie theory back to your work:** "I faced this when I was cutting Presidio latency..."
- **"I don't know, but here's how I'd think about it"** beats bluffing every time.
- **Numbers sell:** 40% latency cut, 50% prompt reduction, 16–18s → 8–12s, 15+ hrs/week saved, 26 Docker images.
